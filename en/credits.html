Credits for the 3D world

Everything on the start page comes from free sources or was built for FREQ. As of 22 October 2026.

3D models

All models were adapted for the website (simplified, new materials and lights, brands removed). Licence CC BY 4.0 in each case.

  • “Stylish street light pole with fixtures duo” by AsXSn — source — modified (street lights)
  • “EV_charging_model” by yuki — source — modified (charging stations)
  • “Small Red Gas Station” by SmashedBones — source — modified (fuel station, no brand)
  • “Autonomous GT Car Interior Design – Manual Mode” by benlockett — source — modified (interior)
  • “Fictional supercar – V12 Goblin” by ollitei — source — modified (convoy car; a fictional vehicle)
  • “Coupe SUV Concept” by gamers_universe — source — modified (convoy car)
  • “Cyberpunk car” by 4d_Bob — source — heavily modified (convoy car)
  • “guardrail road” by danimow — source — modified (guardrails)
  • “Realistic fir trees pack (LODS, gameready)” by LOLIPOP — source — modified (firs)
  • “Realistic Trees Collection” by Jungle Jim — source — modified (broadleaf trees, conifer bush)
  • “Realistic Tree Models For Games” by fadiyasotodeh — source — modified (beech)

The saloon car, the conifers, the interior, fuel pumps, speed camera, billboard and signs of the first version were built for FREQ (Blender), as were all profile pictures (drawn, no real people).

Textures and sky light

  • Asphalt, ground and bark textures: Asphalt 031, Ground 037, Bark 012 by ambientCG — CC0 1.0
  • Night HDRI (sky light and reflections): Narrow Moonlit Road by Greg Zaal, Poly Haven — CC0 1.0
  • Needle texture of the trees, all flares, chips and screens: made in-house

Software

  • three.js (with GLTFLoader, HDRLoader and the meshopt decoder) — MIT licence, text in lizenzen/three.js-MIT.txt
  • Models prepared with Blender and glTF Transform
  • Maps in the app: data © OpenStreetMap contributors (ODbL); the map on the in-car screen is a schematic imitation

The full list with all changes is in the repository under lizenzen/ASSETS.md.
